Überblick

nj.clipboard delegiert direkt an navigator.clipboard.writeText() und navigator.clipboard.readText(). Beide Funktionen sind asynchron und liefern Promises.

FunktionNative GrundlageErgebnis
nj.clipboard.copy(value)navigator.clipboard.writeText()Promise<void>
nj.clipboard.read()navigator.clipboard.readText()Promise<string>
Wichtig: Die Zwischenablage-API ist normalerweise nur in sicheren Kontexten verfügbar, etwa über HTTPS oder auf localhost. Zusätzlich können Browser eine direkte Benutzeraktion und eine Berechtigung verlangen.

nj.clipboard.copy()

nj.clipboard.copy(value) → Promise<void>

Wandelt den übergebenen Wert mit String(value) in Text um und schreibt diesen in die Zwischenablage.

await nj.clipboard.copy("Hallo Welt");

Nicht-string-Werte

await nj.clipboard.copy(4711);        // schreibt "4711"
await nj.clipboard.copy(true);        // schreibt "true"
await nj.clipboard.copy(null);        // schreibt "null"
await nj.clipboard.copy({ id: 1 });   // schreibt "[object Object]"

Objekte sollten daher vorher bewusst serialisiert werden:

const data = { id: 1, status: "ok" };

await nj.clipboard.copy(
  JSON.stringify(data, null, 2)
);

nj.clipboard.read()

nj.clipboard.read() → Promise<string>

Liest Text aus der Zwischenablage und gibt ihn als Promise-Ergebnis zurück.

const text = await nj.clipboard.read();

nj("#clipboard-preview").text(text);

Die Funktion liest ausschließlich Text. Bilder, Dateien oder andere Clipboard-Datentypen werden vom aktuellen Core nicht unterstützt.

Berechtigungen und Browserregeln

Die tatsächliche Ausführung wird durch die Sicherheitsregeln des Browsers bestimmt. Typische Voraussetzungen sind:

  • Ausführung über HTTPS oder localhost.
  • Aufruf nach einer Benutzeraktion, beispielsweise einem Klick.
  • Erlaubnis zum Lesen oder Schreiben der Zwischenablage.
  • Ein aktiver und sichtbarer Browser-Tab.
nj("#copy-button").on("click", async () => {
  await nj.clipboard.copy("Kopierter Inhalt");
});
Insbesondere das Lesen ist in vielen Browsern strenger geschützt als das Schreiben. Ein erfolgreicher Schreibzugriff bedeutet daher nicht automatisch, dass auch read() erlaubt ist.

Fehlerbehandlung

Der Core fängt Fehler der nativen Clipboard-API nicht ab. Ablehnungen müssen deshalb im aufrufenden Code behandelt werden.

try {
  await nj.clipboard.copy("Text");
  nj("#status").text("Kopiert");
} catch (error) {
  console.error(error);
  nj("#status").text("Kopieren nicht möglich");
}

Verfügbarkeit prüfen

if (!navigator.clipboard) {
  console.warn("Clipboard API nicht verfügbar");
}

Eine automatische Fallback-Lösung, etwa über ein temporäres textarea und document.execCommand("copy"), ist nicht Bestandteil von nojquery 4.1.0.

Praxisbeispiele

Code kopieren

nj("[data-copy]").on("click", async function () {
  const selector = this.dataset.copy;
  const text = document.querySelector(selector)?.textContent ?? "";

  try {
    await nj.clipboard.copy(text);
    this.textContent = "Kopiert";
  } catch {
    this.textContent = "Fehler";
  }
});

Aktuelle URL kopieren

nj("#copy-link").on("click", async () => {
  await nj.clipboard.copy(location.href);
});

JSON-Daten kopieren

const exportData = {
  generatedAt: new Date().toISOString(),
  items
};

await nj.clipboard.copy(
  JSON.stringify(exportData, null, 2)
);

Text in ein Feld übernehmen

nj("#paste").on("click", async () => {
  try {
    const value = await nj.clipboard.read();
    nj("#target").val(value);
  } catch (error) {
    console.error("Lesen fehlgeschlagen", error);
  }
});

Grenzen des aktuellen Moduls

  • Nur Textzugriff über writeText() und readText().
  • Keine Unterstützung für Bilder, HTML-Fragmente oder Dateien.
  • Keine integrierte Verfügbarkeitsprüfung.
  • Keine automatische Berechtigungsabfrage.
  • Keine Fallback-Implementierung für ältere Browser.
  • Keine interne Fehlerbehandlung oder Statusmeldung.
  • Keine Funktion zum Leeren der Zwischenablage.

Diese Angaben entsprechen der tatsächlich vorhandenen API in nojquery.core.js.

Querverweise

Events

DOM

Templates

Strukturierte Inhalte vor dem Kopieren aufbereiten.

Validation

Eingelesene Zwischenablage-Inhalte vor der Weiterverarbeitung prüfen.
