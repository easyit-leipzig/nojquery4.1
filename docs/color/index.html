Namespace nj.color

Dieser Namespace stellt Hilfsfunktionen zur Farbkonvertierung und Helligkeitsänderung bereit.

hexToRgb(hex)

nj.color.hexToRgb("#336699") // -> {r:51,g:102,b:153}

Akzeptiert 3- oder 6-stellige Hexwerte und liefert ein Objekt mit den Komponenten r, g und b.

rgbToHex(r,g,b)

nj.color.rgbToHex(51,102,153) // -> "#336699"

Begrenzt Werte automatisch auf den Bereich 0…255 und erzeugt einen Hex-Farbwert.

lighten(hex,p=10)

nj.color.lighten("#336699",20)

Erhöht die Helligkeit um den angegebenen Prozentwert.

darken(hex,p=10)

nj.color.darken("#336699",20)

Verringert die Helligkeit. Intern wird lighten() mit negativem Prozentwert verwendet.
