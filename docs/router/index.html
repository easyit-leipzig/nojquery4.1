History API

Router

Deklariert Pfadmuster, extrahiert benannte Segmente und navigiert ohne vollständigen Seitenreload.

nj.route()start()navigate()replace()params()Grenzen

Grundablauf

nj.route('/users/:id', ({ id }) => {
  nj('#app').html(`<h1>Benutzer ${id}</h1>`);
});

nj.router.start();
nj.navigate('/users/42');
Der Server muss direkte Aufrufe von Anwendungsrouten wieder an die Hauptseite der Anwendung ausliefern.

nj.route(pattern, handler)

nj.route(pattern, handler) → nj

Registriert eine Route. Segmente der Form :name werden als benannte Parameter extrahiert und mit decodeURIComponent() dekodiert.

nj.route('/projects/:project/tasks/:task', (params, path) => {
  console.log(params.project, params.task, path);
});

nj.router.start()

nj.router.start() → nj.router

Wertet sofort location.pathname aus und registriert einen popstate-Listener. Im üblichen Betrieb genau einmal starten.

nj.router.navigate(url, state)

nj.router.navigate(url[, state = {}])

Erzeugt über history.pushState() einen neuen Verlaufseintrag und löst danach die Routenauswertung aus. nj.navigate() ist ein Alias.

nj.navigate('/orders/17', { source: 'dashboard' });

nj.router.replace(url, state)

nj.router.replace(url[, state = {}])

Ersetzt den aktuellen Verlaufseintrag mit history.replaceState() und wertet die Route neu aus.

nj.router.params()

nj.router.params() → Object

Konvertiert den aktuellen Querystring über URLSearchParams in ein Objekt. Werte bleiben Strings; doppelte Namen werden auf den letzten Wert reduziert.

// /search?q=router&page=2
const { q, page } = nj.router.params();

Grenzen des Core-Moduls

  • Keine Middleware oder Guards.
  • Keine Wildcards oder optionalen Parameter.
  • Keine integrierte 404-Route.
  • Keine Methode zum Entfernen registrierter Routen.
  • Keine automatischen Link-Handler.
  • Keine eigenen back(), forward() oder reload()-Methoden.
