Kombinationen.

Die Keyboard-API registriert keydown-Handler für einzelne Tasten und Kombinationen mit Ctrl, Shift, Alt oder Meta.

const off = nj.key.on("ctrl+s", event => {
  event.preventDefault();
  saveDocument();
});

// später:
off();

Überblick

nj.key stellt einen allgemeinen Tastenkombinations-Helfer und zwei Kurzformen für Enter und Escape bereit.

FunktionZweckRückgabe
nj.key.on()Taste oder Kombination registrierenFunktion zum Abmelden
nj.key.enter()Enter auf document registrierenFunktion zum Abmelden
nj.key.escape()Escape auf document registrierenFunktion zum Abmelden
Vergleich: Tastennamen und Kombinationen werden intern in Kleinbuchstaben umgewandelt. Der Abgleich erfolgt gegen event.key.toLowerCase().

nj.key.on()

nj.key.on(combo, handler[, target = document]) → function

Registriert einen keydown-Listener am angegebenen Ziel. Standardziel ist document.

const unregister = nj.key.on("f2", event => {
  console.log("F2 gedrückt", event);
});

Eigenes Ziel

const input = document.querySelector("#search");

const off = nj.key.on("enter", event => {
  runSearch(event.currentTarget.value);
}, input);

Als Ziel wird ein Objekt erwartet, das addEventListener() und removeEventListener() unterstützt.

nj.key.enter()

nj.key.enter(handler) → function

Kurzform für nj.key.on("enter", handler). Die Registrierung erfolgt immer am Standardziel document.

const offEnter = nj.key.enter(event => {
  submitCurrentDialog();
});
Der aktuelle Helper akzeptiert kein eigenes Zielargument. Für ein bestimmtes Element muss nj.key.on("enter", handler, target) verwendet werden.

nj.key.escape()

nj.key.escape(handler) → function

Kurzform für nj.key.on("escape", handler). Die Registrierung erfolgt am document.

const offEscape = nj.key.escape(() => {
  closeModal();
});

Der native event.key-Wert muss dabei "Escape" ergeben. Die alternative Bezeichnung "Esc" wird vom Helper nicht speziell normalisiert.

Tastenkombinationen

Die Kombination wird an Pluszeichen getrennt. Der letzte Teil gilt als Haupttaste, davorstehende unterstützte Teile als Modifikatortasten.

nj.key.on("ctrl+s", save);
nj.key.on("ctrl+shift+p", openCommandPalette);
nj.key.on("alt+arrowdown", openMenu);
nj.key.on("meta+k", openSearch);
Text im Combo-StringGeprüfte Event-Eigenschaft
ctrlevent.ctrlKey
shiftevent.shiftKey
altevent.altKey
metaevent.metaKey
Zusätzliche Modifikatoren: Der aktuelle Abgleich verlangt nur, dass die im String genannten Modifikatoren gedrückt sind. Nicht genannte Modifikatoren werden nicht ausgeschlossen.

Listener wieder entfernen

Jeder Registrierungsaufruf gibt eine Funktion zurück, welche genau den erzeugten keydown-Listener entfernt.

const off = nj.key.on("ctrl+enter", sendMessage);

// Komponente wird entfernt:
off();

Diese Rückgabefunktion sollte bei kurzlebigen Komponenten oder wechselnden Ansichten aufgerufen werden, um doppelte Handler zu vermeiden.

Praxisbeispiele

Speichern mit Ctrl+S

const offSave = nj.key.on("ctrl+s", async event => {
  event.preventDefault();

  await saveDocument();
  nj("#status").text("Gespeichert");
});

Modal mit Escape schließen

const offEscape = nj.key.escape(event => {
  const modal = document.querySelector(".modal.is-open");
  if (!modal) return;

  event.preventDefault();
  modal.classList.remove("is-open");
});

Suche im Eingabefeld

const field = document.querySelector("#search");

nj.key.on("enter", event => {
  event.preventDefault();
  search(field.value);
}, field);

Plattformabhängige Shortcuts

const isMac = /Mac|iPhone|iPad/.test(navigator.platform);
const combo = isMac ? "meta+k" : "ctrl+k";

nj.key.on(combo, event => {
  event.preventDefault();
  openCommandPalette();
});

Grenzen des aktuellen Moduls

  • Nur keydown; keine Helfer für keyup oder keypress.
  • Keine automatische Unterdrückung des Browser-Standardverhaltens.
  • Keine Prüfung, ob Eingabefelder oder editierbare Elemente fokussiert sind.
  • Keine Unterscheidung zwischen linker und rechter Modifikatortaste.
  • Keine Unterstützung für event.code oder tastaturlayout-unabhängige Shortcuts.
  • Keine Sequenzen wie „g dann h“.
  • Keine Alias-Normalisierung für alternative Tastennamen.
  • enter() und escape() akzeptieren kein eigenes Ziel.

Diese Angaben entsprechen der tatsächlich vorhandenen API in nojquery.core.js.
