AJAX & HTTP

Das HTTP-Modul kapselt fetch() für JSON, FormData, Uploads, Zeitüberschreitungen und kontrollierte Abbrüche. Neben nj.request() stehen Kurzformen für GET, POST, PUT, PATCH und DELETE bereit.

Grundprinzip

Alle Anfragen sind asynchron. Sie werden mit await oder über Promise-Ketten verarbeitet.

try {
  const users = await nj.get("/api/users");
  console.log(users);
} catch (error) {
  nj.log.error(error);
}
Antwortformat: JSON-Antworten werden automatisch dekodiert. Andere Antworttypen werden entsprechend dem Content-Type verarbeitet.

Allgemeine Anfrage

nj.request(url, options)

nj.request(url[, options]) → Promise<any>

Zentrale Funktion für alle HTTP-Anfragen.

OptionBeschreibung
methodHTTP-Methode.
headersZusätzliche Header.
bodyAnfragekörper.
timeoutZeitlimit in Millisekunden.
signalExternes AbortSignal.
credentialsCookie- und Zugangsdatenverhalten.
const result = await nj.request("/api/settings", {
  method: "PATCH",
  headers: { "X-CSRF-Token": csrfToken },
  body: { theme: "dark" },
  timeout: 8000
});
Promisefetch-basiert

GET

nj.get(url, options)

nj.get(url[, options]) → Promise<any>

Ruft Daten ab.

const users = await nj.get("/api/users?status=active");

POST

nj.post(url, data, options)

nj.post(url[, data][, options]) → Promise<any>

Erstellt typischerweise eine neue Ressource.

const created = await nj.post("/api/users", {
  firstname: "Olaf",
  lastname: "Thiele"
});

PUT

nj.put(url, data, options)

nj.put(url[, data][, options]) → Promise<any>

Überträgt eine vollständige Ressourcendarstellung.

await nj.put("/api/users/42", {
  firstname: "Olaf",
  lastname: "Thiele",
  active: true
});

PATCH

nj.patch(url, data, options)

nj.patch(url[, data][, options]) → Promise<any>

Überträgt eine partielle Änderung.

await nj.patch("/api/users/42", { active: false });

DELETE

nj.delete(url, data, options)

nj.delete(url[, data][, options]) → Promise<any>

Löscht eine Ressource.

await nj.delete("/api/users/42");

Upload

nj.upload(url, files, options)

nj.upload(url, files[, options]) → Promise<any>

Überträgt einzelne Dateien oder Dateilisten als Multipart-Anfrage.

const input = nj("#documents").get();

await nj.upload("/api/upload", input.files, {
  fieldName: "documents",
  data: { record_id: 42 }
});
Wichtig: Den Multipart-Content-Type nicht manuell setzen. Der Browser ergänzt den Boundary-Wert.

try {
  await nj.get("/api/report", { timeout: 5000 });

  if (error.name === "AbortError") {
    nj("#status").text("Zeitüberschreitung.");
  }

Abbruch

AbortController

let controller;

async function search(term) {
  controller?.abort();
  controller = new AbortController();

  return nj.get(`/api/search?q=${encodeURIComponent(term)}`, {
    signal: controller.signal
  });
}

Antworten

Automatische Verarbeitung

JSON wird dekodiert; Textinhalte werden als String geliefert. Leere Antworten können ohne Nutzdaten zurückkehren.

const config = await nj.get("/api/config");
const fragment = await nj.get("/partials/menu.html");

Fehlerbehandlung

try, catch und finally

const button = nj("#save").prop("disabled", true);

try {
  await nj.post("/api/record", payload);
  nj.bus.emit("record:saved", payload);
} catch (error) {
  nj("#error").text("Speichern fehlgeschlagen.").show();
} finally {
  button.prop("disabled", false);
}

Anwendungsmuster

Formular senden

nj("#contact").on("submit", async event => {
  event.preventDefault();
  const form = nj(event.currentTarget);
  const data = form.serialize();

  await nj.post("/api/contact", data);
  form.trigger("form:sent", data);
});

Datensatz löschen

nj("#records").on("click", "[data-delete]", async function () {
  const row = nj(this).closest("tr");
  await nj.delete(`/api/records/${row.data("id")}`);
  await row.fadeOut(160);
  row.remove();
});

GET mit Cache

let users = nj.cache.memory.get("users");

if (!users) {
  users = await nj.get("/api/users");
  nj.cache.memory.set("users", users, 60000);
}
