Namespace nj.bus

Ein zentraler Ereignisbus auf Basis eines nativen EventTarget.

Überblick

MethodeRückgabeZweck
on(name, handler)der übergebene HandlerRegistriert einen Event-Handler.
off(name, handler)undefinedEntfernt genau diesen Handler.
once(name, handler)undefinedRegistriert einen Handler mit { once: true }.
emit(name, detail)booleanErzeugt ein CustomEvent mit event.detail.

on(name, handler)

nj.bus.on(name, handler)

Die Methode registriert den Handler mit addEventListener() am internen Bus. Anschließend gibt sie dieselbe Handler-Funktion zurück.

const loginHandler = nj.bus.on("user:login", event => {
  console.log(event.detail.name);
});

Der Handler erhält ein Event-Objekt. Die übermittelten Nutzdaten stehen unter event.detail.

off(name, handler)

nj.bus.off(name, handler)

Intern wird removeEventListener(name, handler) aufgerufen. Zum Entfernen muss daher dieselbe Funktionsreferenz verwendet werden, die zuvor registriert wurde.

nj.bus.off("user:login", loginHandler);

Der aktuelle Core besitzt keine Variante zum Entfernen aller Handler eines Ereignisnamens ohne Handlerreferenz.

once(name, handler)

nj.bus.once(name, handler)

Die Registrierung erfolgt mit addEventListener(name, handler, { once: true }). Der Browser entfernt den Handler nach dem ersten Ereignis automatisch.

nj.bus.once("app:ready", event => {
  console.log("Bereit:", event.detail);
});

emit(name, detail)

nj.bus.emit(name, detail)

Die Methode erstellt new CustomEvent(name, { detail }) und übergibt das Ereignis an dispatchEvent(). Die Nutzdaten sind im Handler über event.detail verfügbar.

nj.bus.on("order:created", event => {
  console.log(event.detail.orderId);
  console.log(event.detail.total);
});

nj.bus.emit("order:created", {
  orderId: 4711,
  total: 89.90
});

Der Rückgabewert stammt direkt von EventTarget.dispatchEvent().

Vollständiges Beispiel

const handler = nj.bus.on("data:loaded", event => {
  console.log("Datensätze:", event.detail.count);
});

nj.bus.emit("data:loaded", { count: 12 });
nj.bus.off("data:loaded", handler);
