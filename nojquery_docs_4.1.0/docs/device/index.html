Device

Geräte-, Viewport- und Online-Prüfungen der tatsächlich vorhandenen nj.device-API.

touch() mobile() tablet() desktop() online() Grenzen

Überblick

FunktionPrüfungRückgabe
touch()ontouchstart oder navigator.maxTouchPointsboolean
mobile()Viewport bis 767 pxboolean
tablet()Viewport 768–1024 pxboolean
desktop()Viewport ab 1025 pxboolean
online()navigator.onLineboolean

nj.device.touch()

nj.device.touch() → boolean

Prüft, ob Touch-Unterstützung vorhanden ist.

if (nj.device.touch()) {
  document.body.classList.add("is-touch");
}
Touch-Unterstützung bedeutet nicht, dass ausschließlich Touch verwendet wird. Hybridgeräte können zugleich Maus und Tastatur besitzen.

nj.device.mobile()

nj.device.mobile() → boolean

Verwendet matchMedia("(max-width: 767px)").

if (nj.device.mobile()) {
  nj("#navigation").addClass("navigation--compact");
}

nj.device.tablet()

nj.device.tablet() → boolean

Verwendet matchMedia("(min-width: 768px) and (max-width: 1024px)").

const columns = nj.device.tablet() ? 2 : 3;

nj.device.desktop()

nj.device.desktop() → boolean

Verwendet matchMedia("(min-width: 1025px)").

if (nj.device.desktop()) {
  enableWideLayout();
}

nj.device.online()

nj.device.online() → boolean

Gibt den aktuellen Wert von navigator.onLine zurück.

if (!nj.device.online()) {
  nj("#status").text("Offline");
}
navigator.onLine garantiert nicht, dass eine bestimmte API oder ein Server erreichbar ist.

Praxisbeispiel

function updateEnvironment() {
  document.body.classList.toggle("is-mobile", nj.device.mobile());
  document.body.classList.toggle("is-tablet", nj.device.tablet());
  document.body.classList.toggle("is-desktop", nj.device.desktop());
  document.body.classList.toggle("is-offline", !nj.device.online());
}

updateEnvironment();
window.addEventListener("resize", updateEnvironment);
window.addEventListener("online", updateEnvironment);
window.addEventListener("offline", updateEnvironment);

Grenzen des aktuellen Moduls

  • Keine Browser-, Betriebssystem- oder User-Agent-Erkennung.
  • Mobile, Tablet und Desktop beruhen nur auf Viewportbreiten.
  • Keine automatische Aktualisierung bei Resize.
  • Keine Erkennung von Maus, Stift, Orientierung oder Pixeldichte.
  • online() prüft keine tatsächliche Servererreichbarkeit.
  • Keine eigenen Online-/Offline-Listener.
