Browser URL Utilities

URL

URLs parsen, Queryparameter lesen oder unveränderlich bearbeiten und den Hash der aktuellen Seite verwalten.

API-Überblick

MethodeRückgabeZweck
parse()URLRelative oder absolute URL auflösen
get()String | nullQuerywert lesen
set()StringQuerywert in neuer URL setzen
remove()StringQuerywert aus neuer URL entfernen
query()ObjectQuerystring als Objekt
hash()StringHash lesen oder schreiben

nj.url.parse(value)

nj.url.parse([value]) → URL

Erzeugt ein natives URL-Objekt. Ohne Argument wird location.href verwendet; relative Werte werden gegen die aktuelle URL aufgelöst.

const url = nj.url.parse('/docs?page=2');
console.log(url.pathname);     // /docs
console.log(url.searchParams);

nj.url.get(name, value)

nj.url.get(name[, value = location.href]) → String | null

Liest einen einzelnen Queryparameter aus der angegebenen oder aktuellen URL.

nj.url.get('page', '/docs?page=2'); // '2'

nj.url.set(name, val, value)

nj.url.set(name, val[, value = location.href]) → String

Setzt oder ersetzt einen Queryparameter und gibt die resultierende URL als String zurück. Die Browseradresse wird nicht automatisch geändert.

const next = nj.url.set('page', 3, '/docs?sort=name');
// absolute URL mit sort=name&page=3

nj.url.remove(name, value)

nj.url.remove(name[, value = location.href]) → String

Entfernt alle Werte des Parameternamens aus einer neu erzeugten URL und gibt diese als String zurück.

nj.url.query(value)

nj.url.query([value = location.href]) → Object

Erzeugt mit Object.fromEntries() ein einfaches Objekt. Alle Werte sind Strings; bei mehrfach vorkommenden Namen bleibt der letzte Wert erhalten.

nj.url.query('/search?q=api&page=2');
// { q: 'api', page: '2' }

nj.url.hash(value)

nj.url.hash() → String
nj.url.hash(value) → value

Ohne Argument wird location.hash ohne führendes # gelesen. Mit Argument wird der Hash der aktuellen Seite gesetzt.

const section = nj.url.hash();
nj.url.hash('examples');
Das Schreiben des Hashes verändert die aktuelle Browseradresse und kann ein hashchange-Ereignis auslösen.

Praxisbeispiele

Filter aktualisieren und navigieren

let url = nj.url.set('category', 'books', location.href);
url = nj.url.set('page', 1, url);
nj.navigate(new URL(url).pathname + new URL(url).search);

Parameter sicher auslesen

const page = Number(nj.url.get('page') || 1);
const filter = nj.url.get('filter') || 'all';

Grenzen und Verhalten

  • set() und remove() ändern die aktuelle Seite nicht.
  • query() bildet Mehrfachparameter nicht als Array ab.
  • Werte werden vom nativen URLSearchParams codiert und dekodiert.
  • Das Modul besitzt keine Methoden build(), current(), base(), origin(), pathname(), param() oder params().
