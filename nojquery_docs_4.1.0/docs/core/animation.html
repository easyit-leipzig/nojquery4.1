Animationen

Die Animations-API basiert auf der Web Animations API. Sie deckt freie Keyframe-Animationen sowie fertige Effekte für Einblenden, Ausblenden, Auf- und Zuklappen, Zoom und visuelles Hervorheben ab.

Grundprinzip

Animationen werden mit nativen Element.animate()-Aufrufen erzeugt. Freie Animationen arbeiten mit Keyframes und Timing-Optionen. Komfortmethoden kapseln typische UI-Effekte.

await nj(".card").animate(
  [
    { opacity: 0, transform: "translateY(12px)" },
    { opacity: 1, transform: "translateY(0)" }
  ],
  { duration: 250, easing: "ease-out" }
);
Asynchrones Verhalten: Animationsmethoden liefern ein Promise, sobald die Bibliothek auf den Abschluss der nativen Animationen wartet. Dadurch lassen sich Animationen sauber mit await koordinieren.

Freie Animationen

animate(keyframes, options)

wrapper.animate(keyframes[, options]) → Promise<NJ>

Animiert alle ausgewählten Elemente mit frei definierten Keyframes. Die Methode sammelt die nativen Animationen und wartet auf deren Abschluss.

ParameterTypBeschreibung
keyframesArray | ObjectKeyframes gemäß Web Animations API.
optionsNumber | ObjectDauer in Millisekunden oder vollständige Timing-Optionen.
await nj("#panel").animate(
  [
    { opacity: 0, transform: "scale(.96)" },
    { opacity: 1, transform: "scale(1)" }
  ],
  {
    duration: 220,
    easing: "cubic-bezier(.2,.8,.2,1)",
    fill: "both"
  }
);
Rückgabe: Promise<NJ>mehrere Elemente

Fade-Effekte

fadeIn(duration)

wrapper.fadeIn([duration]) → Promise<NJ>

Blendet zuvor versteckte Elemente ein. Der Effekt animiert die Deckkraft von 0 auf 1 und stellt sicher, dass die Elemente sichtbar sind.

await nj("#notice").fadeIn(240);

fadeOut(duration)

wrapper.fadeOut([duration]) → Promise<NJ>

Blendet Elemente aus und setzt sie nach Abschluss auf unsichtbar.

await nj("#notice").fadeOut(180);

Hinweis: Nach dem Ausblenden ist das Element nicht mehr sichtbar. Für eine reine Opacity-Animation ohne anschließendes Verbergen ist animate() zu verwenden.

Slide-Effekte

slideToggle(duration)

wrapper.slideToggle([duration]) → Promise<NJ>

Öffnet oder schließt die Auswahl abhängig vom aktuellen Sichtbarkeitszustand.

nj("#toggle-details").on("click", async () => {
  await nj("#details").slideToggle(220);
});

Zoom-Effekte

zoomIn(duration)

wrapper.zoomIn([duration]) → Promise<NJ>

Blendet ein Element mit einer kombinierten Scale- und Opacity-Animation ein.

await nj("#dialog").zoomIn(180);

zoomOut(duration)

wrapper.zoomOut([duration]) → Promise<NJ>

Verkleinert und verblasst ein Element. Nach Abschluss wird es verborgen.

await nj("#dialog").zoomOut(160);

Visuelle Hervorhebung

shake(duration)

wrapper.shake([duration]) → Promise<NJ>

Bewegt Elemente kurz horizontal hin und her. Der Effekt eignet sich für fehlerhafte Eingaben, abgelehnte Aktionen oder besonders wichtige Hinweise.

if (!nj("#email").val()) {
  await nj("#email").shake(320);
  nj("#email").get()?.focus();
}

Barrierefreiheit: Bewegung sollte sparsam eingesetzt werden. Bei Nutzern mit reduzierter Bewegungspräferenz empfiehlt sich ein alternativer visueller Zustand, etwa eine Fehlerklasse.

Timing-Optionen

Unterstützte Optionen

OptionBedeutung
durationDauer der Animation in Millisekunden.
delayVerzögerung vor Beginn.
easingZeitfunktion wie linear, ease oder cubic-bezier(...).
fillÜbernahme der Keyframe-Werte vor oder nach der Laufzeit.
iterationsAnzahl der Wiederholungen.
directionRichtung, etwa normal, reverse oder alternate.
await nj(".pulse").animate(
  [
    { transform: "scale(1)" },
    { transform: "scale(1.04)" },
    { transform: "scale(1)" }
  ],
  {
    duration: 420,
    easing: "ease-in-out",
    iterations: 2
  }
);

Promises und Reihenfolgen

Animationen nacheinander

await nj("#dialog").fadeIn(160);
await nj("#dialog-content").zoomIn(180);

Mit await beginnt die zweite Animation erst nach dem Ende der ersten.

Animationen parallel

await Promise.all([
  nj("#sidebar").animate({ opacity: 1 }, { duration: 220 }),
  nj("#overlay").fadeIn(180)
]);

Promise.all() wartet, bis alle beteiligten Animationen abgeschlossen sind.

Anwendungsmuster

Akkordeon

nj("[data-accordion]").on("click", "button", async function () {
  const panel = nj(this).next();
  const open = this.getAttribute("aria-expanded") === "true";

  this.setAttribute("aria-expanded", String(!open));
  await panel.slideToggle(220);
});

Toast-Nachricht

async function showToast(message) {
  nj("#toast").text(message);
  await nj("#toast").fadeIn(160);

  setTimeout(() => {
    nj("#toast").fadeOut(180);
  }, 2500);
}

Dialog öffnen

await Promise.all([
  nj("#dialog-overlay").fadeIn(140),
  nj("#dialog").zoomIn(180)
]);

Formularfehler

const invalid = nj("#form :invalid");

if (invalid.exists()) {
  invalid.addClass("field-error");
  await invalid.first().shake(280);
}

Performance und Zugänglichkeit

Empfehlungen

Animationen von transform und opacity sind meist günstiger als häufige Änderungen layoutrelevanter Eigenschaften. Slide-Effekte benötigen Höhenmessungen und sollten bei sehr großen Elementmengen gezielt eingesetzt werden.

const reduceMotion = window.matchMedia(
  "(prefers-reduced-motion: reduce)"
).matches;

if (reduceMotion) {
  nj("#panel").show();
} else {
  await nj("#panel").animate({ opacity: 1 }, { duration: 220 });
}
