Core Utilities

Direkte Hilfsfunktionen und Grundfunktionen des nojquery-Core.

Einordnung

Der Generator führt diesen Bereich als nj.core mit dem Unterbereich utilities. Im JavaScript-Core ist nj.core jedoch kein separates Namespace-Objekt. Dokumentiert werden deshalb die tatsächlich unmittelbar unter nj definierten Hilfsfunktionen.
