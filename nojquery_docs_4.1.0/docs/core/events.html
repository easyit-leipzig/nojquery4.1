Events

Die Events-API verbindet native DOM-Ereignisse mit einer verkettbaren Schnittstelle. Sie unterstützt mehrere Ereignisnamen, Delegation, gezieltes Entfernen, einmalige Handler, benutzerdefinierte Ereignisse und einen globalen EventBus.

Grundprinzip

Die Methoden on(), off(), once() und trigger() arbeiten mit nativen DOM-Ereignissen. nojquery speichert registrierte Handler intern am jeweiligen Element, damit sie später auch bei delegierten Ereignissen zuverlässig entfernt werden können.

nj("#save").on("click", event => {
  event.preventDefault();
  saveRecord();
});
Verkettung: Die DOM-Eventmethoden geben den aktuellen NJ-Wrapper zurück. Dadurch lassen sich Listener direkt mit Klassen-, Attribut- oder Sichtbarkeitsoperationen kombinieren.

Listener registrieren

on(events, selector, handler, options)

wrapper.on(events, handler[, options]) → NJ wrapper.on(events, selector, handler[, options]) → NJ

Registriert einen oder mehrere Event-Listener auf allen ausgewählten Elementen. Mehrere Ereignisnamen werden durch Leerzeichen getrennt.

ParameterTypBeschreibung
eventsStringEin oder mehrere Ereignisnamen, etwa "click" oder "focus blur".
selectorStringOptionaler CSS-Selektor für Delegation.
handlerFunctionAuszuführende Callback-Funktion.
optionsBoolean | ObjectOptionen für addEventListener().
Rückgabe: NJverkettbarmehrere Events
nj("#search").on("focus blur", event => {
  nj(event.currentTarget).toggleClass("active", event.type === "focus");
});

Event-Delegation

Bei delegierten Ereignissen sitzt der eigentliche Listener auf einem stabilen Elternelement. nojquery sucht vom Ereignisziel aus mit closest(selector) nach dem passenden Element.

Delegierte Listener

wrapper.on(events, selector, handler[, options]) → NJ

Delegation eignet sich besonders für dynamisch nachgeladene Listen, Tabellen, Menüs und CRUD-Oberflächen.

nj("#user-table").on("click", "button[data-action='edit']", function (event) {
  const row = nj(this).closest("tr");
  const id = row.data("id");

  openEditor(id);
});
this im Handler: Bei einer normalen Funktion verweist this auf das Element, das dem delegierten Selektor entspricht. Bei einer Arrow-Funktion gibt es diese Bindung nicht.

Delegationsgrenze

Ein delegierter Treffer wird nur verarbeitet, wenn er innerhalb des Elements liegt, auf dem der Listener registriert wurde. Dadurch reagiert ein Tabellen-Listener nicht auf gleichartige Schaltflächen außerhalb der Tabelle.

Listener entfernen

off(events, handler)

wrapper.off([events][, handler]) → NJ

Entfernt zuvor mit on() oder once() registrierte Listener. Ohne Argumente werden alle von nojquery verwalteten Listener der Auswahl entfernt.

AufrufWirkung
off()Entfernt alle gespeicherten Listener.
off("click")Entfernt alle Click-Listener.
off("click", handler)Entfernt nur den angegebenen Click-Handler.
off(null, handler)Entfernt den Handler unabhängig vom Ereignisnamen.
function handleSave(event) {
  event.preventDefault();
}

const button = nj("#save");
button.on("click", handleSave);

// Später:
button.off("click", handleSave);

Wichtig: Eine neu geschriebene anonyme Funktion ist nicht dieselbe Funktionsreferenz. Zum gezielten Entfernen muss der ursprüngliche Handler gespeichert werden.

Einmalige Listener

once(events, selector, handler, options)

wrapper.once(events, handler[, options]) → NJ wrapper.once(events, selector, handler[, options]) → NJ

Registriert Listener mit der nativen Option once: true. Nach der ersten Ausführung entfernt der Browser den Listener automatisch.

nj("#intro-video").once("play", () => {
  nj.log.info("Video wurde erstmals gestartet.");
});

Delegierte einmalige Listener sind ebenfalls möglich:

nj("#steps").once("click", ".start-button", function () {
  startWizard();
});

Benutzerdefinierte Ereignisse auslösen

trigger(name, detail)

wrapper.trigger(name[, detail]) → NJ

Erzeugt für jedes ausgewählte Element ein CustomEvent. Das Ereignis ist standardmäßig bubbles: true und cancelable: true.

nj("#editor").on("record:saved", event => {
  console.log(event.detail.id);
});

nj("#editor").trigger("record:saved", {
  id: 42,
  status: "completed"
});
Datenzugriff: Zusätzliche Daten stehen im Listener unter event.detail zur Verfügung.

Ereignisnamen

Für anwendungsspezifische Ereignisse empfiehlt sich eine klare Benennung wie record:saved, menu:opened oder form:validated. Der Doppelpunkt ist lediglich eine Konvention und kein technischer Namespace.

Listener-Optionen

addEventListener-Optionen

Die options werden direkt an addEventListener() weitergereicht.

nj(window).on("scroll", handleScroll, {
  passive: true
});

nj(document).on("click", handleCapture, {
  capture: true
});
OptionVerwendung
captureListener in der Capture-Phase ausführen.
passiveSignalisiert, dass preventDefault() nicht verwendet wird.
onceNach einmaliger Ausführung entfernen; normalerweise über once().
signalListener über einen AbortController beenden.

Globaler EventBus

nj.bus verwendet ein internes EventTarget. Es eignet sich für lose gekoppelte Kommunikation zwischen Modulen, die nicht über dieselben DOM-Elemente verbunden sind.

nj.bus.on(name, handler)

nj.bus.on(name, handler) → handler

Registriert einen globalen Handler und gibt dieselbe Handler-Funktion zurück.

const unsubscribeTarget = nj.bus.on("user:updated", event => {
  refreshUserView(event.detail);
});

nj.bus.off(name, handler)

nj.bus.off(name, handler) → undefined

Entfernt einen bestimmten globalen Handler.

nj.bus.off("user:updated", unsubscribeTarget);

nj.bus.once(name, handler)

nj.bus.once(name, handler) → undefined

Registriert einen globalen Handler für genau eine Ausführung.

nj.bus.emit(name, detail)

nj.bus.emit(name[, detail]) → Boolean

Sendet ein globales CustomEvent. Der Rückgabewert stammt von dispatchEvent().

nj.bus.emit("user:updated", {
  id: 42,
  name: "Olaf"
});
DOM-Event oder EventBus? Verwende DOM-Events, wenn das Ereignis zu einem konkreten Element gehört. Verwende nj.bus, wenn unabhängige Anwendungsmodule miteinander kommunizieren sollen.

Anwendungsmuster

CRUD-Tabelle

nj("#records").on("click", "[data-action]", function () {
  const action = this.dataset.action;
  const id = nj(this).closest("tr").data("id");

  nj.bus.emit(`record:${action}`, { id });
});

Formularworkflow

nj("#contact").on("submit", async event => {
  event.preventDefault();

  const data = nj(event.currentTarget).serialize();
  await nj.post("/api/contact", data);

  nj(event.currentTarget).trigger("form:sent", data);
});

Einmaliger Dialogstart

nj("#open-help").once("click", async () => {
  await loadHelpContent();
  nj("#help-dialog").show();
});

Modulübergreifende Meldung

nj.bus.on("status:changed", event => {
  nj("#global-status").text(event.detail.message);
});

nj.bus.emit("status:changed", {
  message: "Synchronisierung abgeschlossen"
});

Typische Fehler

Anonyme Funktion später entfernen

// Nicht entfernbar über eine neue Funktion:
nj("#save").on("click", () => save());
nj("#save").off("click", () => save());

Die beiden Arrow-Funktionen sind unterschiedliche Objekte. Speichere den Handler stattdessen in einer Variablen.

this in einer Arrow-Funktion erwarten

Delegierte Handler binden this nur bei normalen Funktionen. In Arrow-Funktionen sollte event.target, event.currentTarget oder eine normale Funktion verwendet werden.

preventDefault() bei passivem Listener

Ein Listener mit passive: true darf das Standardverhalten nicht verhindern. Diese Option ist vor allem für Scroll- und Touch-Ereignisse gedacht.
