DOM & Core

Grundprinzip

nj(selector) erzeugt ein NJ-Objekt. Schreibende Methoden geben überwiegend den Wrapper zurück und sind verkettbar. Lesende Methoden beziehen sich grundsätzlich auf das erste gefundene Element.

Sicherheit: Für ungeprüfte Benutzereingaben ist text() statt html() zu verwenden.
nj(".card").addClass("ready").attr("aria-live", "polite").show();

Selektieren

nj(selector, context)

nj(selector[, context]) → NJ

Erzeugt einen NJ-Wrapper aus CSS-Selektoren, DOM-Knoten, NodeLists, HTMLCollections, Arrays oder NJ-Objekten. Der optionale Kontext begrenzt die Suche.

Rückgabe: NJ; verkettbar
const cards = nj(".card");
const links = nj("a", "#menu");
const body = nj(document.body);

length / e

wrapper.length · wrapper.e

length enthält die Trefferzahl. e liefert bei einem Treffer das DOM-Element, bei mehreren Treffern eine Array-Kopie mit item(index), bei leerer Auswahl null.

Rückgabe: Zahl bzw. Element/Array/null
const items = nj(".item");
console.log(items.length);
console.log(items.e);

Iteration

each(callback)

wrapper.each((index, element) => { ... }) → NJ

Führt den Callback für jedes Element aus. In normalen Funktionen verweist this auf das aktuelle DOM-Element.

Rückgabe: NJ; verkettbar
nj(".item").each(function (index) {
  this.dataset.position = String(index);
});

map(callback)

wrapper.map((index, element) => value) → Array

Transformiert die Auswahl in ein normales Array von Rückgabewerten.

Rückgabe: Array; nicht verkettbar
const ids = nj("[id]").map((i, el) => el.id);

Elementzugriff

get(index = 0)

wrapper.get([index]) → Element | undefined

Liefert ein unverpacktes DOM-Element. Negative Indizes zählen vom Ende.

Rückgabe: Element oder undefined
const first = nj(".item").get();
const last = nj(".item").get(-1);

first(), last(), eq(index)

wrapper.first() / last() / eq(index) → NJ

Erzeugen neue NJ-Wrapper mit höchstens einem Element. eq() unterstützt negative Indizes.

Rückgabe: NJ; verkettbar
nj(".item").first().addClass("first");
nj(".item").eq(2).text("Drittes Element");

Traversierung

find(selector)

wrapper.find(selector) → NJ

Sucht in allen aktuellen Elementen nach Nachfahren und entfernt doppelte Treffer.

Rückgabe: NJ
nj("#sidebar").find("a.active").removeClass("active");

closest(selector)

wrapper.closest(selector) → NJ

Liefert den nächstgelegenen passenden Vorfahren einschließlich des Elements selbst.

Rückgabe: NJ
nj(event.target).closest(".card").addClass("selected");

parent() / children(selector)

wrapper.parent() / children([selector]) → NJ

Liefert direkte Elternelemente oder direkte Kinder. children() kann optional filtern.

Rückgabe: NJ
nj(".field").parent().addClass("field-row");
nj("#menu").children("li.active");

next() / prev()

wrapper.next() / prev() → NJ

Liefert das unmittelbar folgende oder vorhergehende Elementgeschwister.

Rückgabe: NJ
nj(".current").next().addClass("upcoming");

Inhalte und Werte

html(value)

wrapper.html() → String | undefined wrapper.html(value) → NJ

Liest oder setzt innerHTML. Ungeprüfte Benutzereingaben dürfen nicht direkt eingesetzt werden.

Rückgabe: String oder NJ
const markup = nj("#result").html();
nj("#result").html("<strong>Fertig</strong>");

text(value)

wrapper.text() → String | undefined wrapper.text(value) → NJ

Liest oder setzt textContent. HTML-Zeichen werden sicher als Text behandelt.

Rückgabe: String oder NJ
nj("#status").text("Datensatz gespeichert.");

val(value)

wrapper.val() → any wrapper.val(value) → NJ

Liest oder setzt die value-Eigenschaft von Eingaben, Textbereichen und Auswahllisten.

Rückgabe: Wert oder NJ
const email = nj("#email").val();
nj("#email").val("name@example.org");

Einfügen

append() / prepend()

wrapper.append(content) / prepend(content) → NJ

Fügt Strings als HTML oder DOM-Knoten/NJ-Auswahlen am Ende beziehungsweise Anfang ein. Bei mehreren Zielen werden Knoten geklont.

Rückgabe: NJ
nj("#list").append("<li>Neu</li>");
nj(".card").prepend(nj.create("span", { text: "Neu" }));

before() / after()

wrapper.before(content) / after(content) → NJ

Fügt Inhalte unmittelbar vor oder nach den ausgewählten Elementen ein.

Rückgabe: NJ
nj("#submit").before("<p class="hint">Prüfen</p>");

appendTo(target)

wrapper.appendTo(target) → NJ

Verschiebt alle ausgewählten Elemente in das erste gefundene Zielelement.

Rückgabe: NJ
nj(".notification").appendTo("#notification-area");

Leeren und Entfernen

empty()

wrapper.empty() → NJ

Entfernt alle Kindknoten, lässt das ausgewählte Element bestehen.

Rückgabe: NJ
nj("#results").empty();

remove()

wrapper.remove() → NJ

Entfernt alle ausgewählten Elemente aus dem DOM.

Rückgabe: NJ
nj(".obsolete").remove();

Attribute, Eigenschaften und Daten

attr(name, value)

wrapper.attr(name) / attr(name,value) / attr(object)

Liest ein Attribut des ersten Elements oder setzt eines beziehungsweise mehrere Attribute auf allen Elementen.

Rückgabe: String/null/undefined oder NJ
nj("a.external").attr({ target: "_blank", rel: "noopener" });

removeAttr() / hasAttr()

wrapper.removeAttr(name) → NJ wrapper.hasAttr(name) → Boolean

Entfernt ein Attribut oder prüft es am ersten Element.

Rückgabe: NJ bzw. Boolean
nj("#dialog").removeAttr("hidden");

prop(name, value)

wrapper.prop(name) / prop(name,value)

Liest oder setzt DOM-Eigenschaften wie disabled, selected oder checked.

Rückgabe: Wert oder NJ
nj("#submit").prop("disabled", true);

data() / removeData()

wrapper.data(name[,value]) / removeData(name)

Arbeitet mit dataset. Setzwerte werden in Strings umgewandelt.

Rückgabe: String/undefined oder NJ
nj(".row").data("recordId", 42);

CSS-Klassen

addClass() / removeClass()

wrapper.addClass(classes) / removeClass(classes) → NJ

Fügt eine oder mehrere leerzeichengetrennte Klassen hinzu oder entfernt sie.

Rückgabe: NJ
nj(".card").addClass("visible highlighted");

toggleClass(name, force)

wrapper.toggleClass(name[,force]) → NJ

Schaltet eine Klasse um oder setzt ihren Zustand über force explizit.

Rückgabe: NJ
nj("#menu").toggleClass("open", shouldOpen);

hasClass(name)

wrapper.hasClass(name) → Boolean

Prüft die Klasse am ersten Element.

Rückgabe: Boolean
if (nj("#menu").hasClass("open")) { /* ... */ }

CSS und Sichtbarkeit

css(property, value)

wrapper.css(property) / css(property,value) / css(object)

Liest berechnete CSS-Werte oder setzt Inline-Styles. CSS-Variablen mit -- werden unterstützt.

Rückgabe: String/undefined oder NJ
nj(".panel").css({ maxHeight: "30rem", "--gap": "1rem" });

removeCss(property)

wrapper.removeCss(property) → NJ

Entfernt eine Inline-CSS-Eigenschaft über removeProperty().

Rückgabe: NJ
nj(".panel").removeCss("max-height");

show() / hide() / toggle()

wrapper.show([display]) / hide() / toggle([display]) → NJ

Steuert die Sichtbarkeit über hidden und display.

Rückgabe: NJ
nj("#details").show("grid");
nj("#details").toggle("flex");

Formulare

checked(value)

wrapper.checked() → Boolean wrapper.checked(value) → NJ

Liest den Checked-Zustand des ersten Elements oder setzt ihn auf allen Elementen.

Rückgabe: Boolean oder NJ
const accepted = nj("#terms").checked();

serialize()

wrapper.serialize() → Object

Wandelt das erste Formular über FormData in ein Objekt um. Doppelte Feldnamen werden Arrays.

Rückgabe: Object
const payload = nj("#contact-form").serialize();

Geometrie und Scrollen

rect()

wrapper.rect() → DOMRect | undefined

Liefert getBoundingClientRect() des ersten Elements.

Rückgabe: DOMRect oder undefined
const bounds = nj("#target").rect();

scrollIntoView(options)

wrapper.scrollIntoView([options]) → NJ

Scrollt Elemente in den sichtbaren Bereich. Standard: smooth und block:start.

Rückgabe: NJ
nj("#errors").scrollIntoView({ behavior: "smooth", block: "center" });

Zustandsprüfungen

is(selector)

wrapper.is(selector) → Boolean

Prüft, ob das erste Element dem CSS-Selektor entspricht.

Rückgabe: Boolean
nj(event.target).is("button[data-action]");

exists()

wrapper.exists() → Boolean

Prüft, ob mindestens ein Element gefunden wurde.

Rückgabe: Boolean
if (nj("#admin-panel").exists()) initializeAdmin();
