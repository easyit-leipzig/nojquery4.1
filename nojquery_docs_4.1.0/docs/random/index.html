Namespace nj.random

Hilfsfunktionen für zufällige Ganzzahlen, Fließkommazahlen, Zeichenketten, Farben und UUIDs.

Überblick

int(min, max)

nj.random.int(min, max)

Die Methode erzeugt eine Ganzzahl im geschlossenen Intervall von min bis max. Beide Grenzen können als Ergebnis auftreten.

const wuerfel = nj.random.int(1, 6);
const index = nj.random.int(0, 9);

Der Core vertauscht die Grenzen nicht automatisch. min sollte kleiner oder gleich max sein.

float(min = 0, max = 1)

nj.random.float(min = 0, max = 1)

Die Berechnung erfolgt mit Math.random() * (max - min) + min. Der untere Grenzwert ist eingeschlossen; der obere Grenzwert wird normalerweise nicht erreicht.

const normalisiert = nj.random.float();
const temperatur = nj.random.float(-10, 35);

string(length = 12, chars = "...")

nj.random.string(length = 12, chars = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789")

Für jede Position wird zufällig ein Zeichen aus chars ausgewählt. Ohne Parameter entsteht eine zwölf Zeichen lange alphanumerische Zeichenfolge.

const token = nj.random.string();
const pin = nj.random.string(6, "0123456789");
const code = nj.random.string(8, "ABCDEFGHJKLMNPQRSTUVWXYZ23456789");

Ein leerer Zeichenvorrat wird vom Core nicht gesondert validiert.

color()

nj.random.color()

Die Methode erzeugt eine Hexadezimalzahl, ergänzt links führende Nullen und gibt eine Zeichenfolge im Format #rrggbb zurück.

const farbe = nj.random.color();
document.body.style.backgroundColor = farbe;

Durch die aktuelle Multiplikation mit 0xffffff kann der exakte Wert #ffffff nicht entstehen.

uuid()

nj.random.uuid()

nj.random.uuid verweist direkt auf nj.uuid. Unterstützt die Laufzeit crypto.randomUUID(), wird diese Funktion verwendet. Andernfalls erzeugt der Core eine UUID-ähnliche Zeichenfolge nach dem Muster xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx.

const id = nj.random.uuid();

Die Fallback-Variante verwendet Math.random() und ist nicht kryptografisch sicher.
