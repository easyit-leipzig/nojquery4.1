Konfiguration

Vollständige Referenz des im Core tatsächlich vorhandenen Objekts nj.config.

ÜberblickOptionenBeispieleWirkung

Überblick

nj.config ist ein frei veränderbares Konfigurationsobjekt. Es besitzt im ausgelieferten Core keine eigenen Methoden.

nj.config = {
  debug: false,
  warn: true,
  exposeUnderscore: true,
  exposeDollar: false,
  forceAliasOverwrite: false,
  ajaxTimeout: 8000,
  animation: {
    duration: 300,
    easing: "ease"
  }
};

Optionen

EigenschaftStandardBedeutung
debugfalseAktiviert zusätzliche Fehler- und Logger-Ausgaben.
warntrueErlaubt Warnungen, insbesondere bei Alias-Konflikten.
exposeUnderscoretrueGibt _ beim Alias-Setup standardmäßig für nj frei.
exposeDollarfalseGibt $ beim Alias-Setup standardmäßig nicht frei.
forceAliasOverwritefalseVerhindert standardmäßig das Überschreiben bereits belegter Aliase.
ajaxTimeout8000Standard-Timeout für Requests in Millisekunden.
animation.duration300Standarddauer für Animationen in Millisekunden.
animation.easing"ease"Standard-Easing für Animationen.

Beispiele

nj.config.debug = true;
nj.config.ajaxTimeout = 12000;
nj.config.animation.duration = 450;
nj.config.animation.easing = "ease-in-out";
Konfigurationswerte sollten vor der ersten Nutzung der davon abhängigen Funktionen gesetzt werden.

Tatsächliche Verwendung im Core

  • debug steuert Diagnoseausgaben in Selektor-, Storage- und weiteren Fehlerpfaden sowie im Logger.
  • warn steuert Warnungen bei belegten Aliasnamen.
  • Die Aliasoptionen werden von nj.exposeAliases() gelesen.
  • ajaxTimeout wird als Standardwert für HTTP-Anfragen verwendet.
  • Die Animationswerte werden von animate(), Fade-, Slide- und Zoom-Funktionen verwendet.
