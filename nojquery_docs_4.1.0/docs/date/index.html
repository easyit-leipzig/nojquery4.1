Namespace nj.date

Hilfsfunktionen für Tagesbeginn, Datumsverschiebung, Zeitdifferenzen und lokalisierte Datumsformatierung.

Überblick

MethodeRückgabeZweck
today()DateErzeugt den heutigen Tag um 00:00:00.000 Uhr in lokaler Zeit.
addDays(d, n)DateErzeugt eine neue Datumsinstanz und verschiebt sie um n Kalendertage.
diff(a, b, unit = "days")numberBerechnet die Zeitdifferenz von a bis b.
format(d, locale = navigator.language, opt = {})stringFormatiert ein Datum mit Intl.DateTimeFormat.

today()

nj.date.today()

Die Funktion erzeugt ein neues Date-Objekt für das aktuelle lokale Datum und setzt Stunden, Minuten, Sekunden und Millisekunden auf null.

const start = nj.date.today();
console.log(start); // heutiges Datum, 00:00:00.000

addDays(d, n)

nj.date.addDays(d, n)

d wird über new Date(d) in eine neue Datumsinstanz überführt. Anschließend wird der Kalendertag mit setDate() um n verschoben. Das übergebene Objekt wird dadurch nicht direkt verändert.

const basis = new Date("2026-07-24T12:00:00");
const spaeter = nj.date.addDays(basis, 5);
const frueher = nj.date.addDays(basis, -2);

Da die Methode mit Kalendertagen arbeitet, können Zeitzonen- und Sommerzeitübergänge die Differenz in Millisekunden beeinflussen.

diff(a, b, unit = "days")

nj.date.diff(a, b, unit = "days")

Die Methode berechnet new Date(b) - new Date(a) und teilt das Ergebnis durch den Faktor der gewünschten Einheit.

unitTeiler
"seconds"1.000
"minutes"60.000
"hours"3.600.000
"days"86.400.000
nj.date.diff("2026-07-20", "2026-07-24");          // 4
nj.date.diff("2026-07-24T08:00", "2026-07-24T10:30", "hours"); // 2.5

Eine unbekannte Einheit verwendet den Divisor 1; das Ergebnis entspricht dann der Differenz in Millisekunden.

format(d, locale = navigator.language, opt = {})

nj.date.format(d, locale = navigator.language, opt = {})

Das Datum wird mit new Intl.DateTimeFormat(locale, opt) formatiert. Ohne explizite Sprache wird navigator.language verwendet.

nj.date.format("2026-07-24", "de-DE");

nj.date.format("2026-07-24", "de-DE", {
  weekday: "long",
  year: "numeric",
  month: "long",
  day: "numeric"
});

Die konkrete Ausgabe hängt von Laufzeit, Gebietsschema, Zeitzone und den übergebenen Optionen ab.
