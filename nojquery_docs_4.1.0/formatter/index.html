Überblick

nj.format bündelt fünf reine Formatierungsfunktionen. Die Standard-Locale ist jeweils navigator.language, sofern kein eigener Wert übergeben wird.

Hinweis: Die Ergebnisse hängen von Browser, Locale, Währung und übergebenen Intl-Optionen ab. Die Beispiele zeigen typische Ausgaben, keine garantiert identischen Zeichenfolgen in jedem Browser.

API

nj.format.number()

nj.format.number(value[, locale = navigator.language][, options = {}]) → string

Formatiert eine Zahl mit Intl.NumberFormat. Alle gültigen Optionen des nativen Formatters können weitergereicht werden.

nj.format.number(1234567.89, "de-DE");
// "1.234.567,89"

nj.format.number(12.3456, "de-DE", {
  minimumFractionDigits: 2,
  maximumFractionDigits: 2
});
// "12,35"

nj.format.money()

nj.format.money(value[, currency = "EUR"][, locale = navigator.language]) → string

Formatiert einen Wert als Währung. Der ISO-Währungscode wird an Intl.NumberFormat übergeben.

nj.format.money(49.9, "EUR", "de-DE");
// "49,90 €"

nj.format.money(49.9, "USD", "en-US");
// "$49.90"

nj.format.percent()

nj.format.percent(value[, locale = navigator.language][, options = {}]) → string

Formatiert einen Verhältniswert als Prozentzahl. Wie bei Intl.NumberFormat entspricht 1 dabei 100 Prozent.

nj.format.percent(0.375, "de-DE");
// "38 %"

nj.format.percent(0.375, "de-DE", {
  minimumFractionDigits: 1
});
// "37,5 %"

nj.format.date()

nj.format.date(value[, locale = navigator.language][, options = {}]) → string

Erzeugt zunächst new Date(value) und formatiert diesen Wert anschließend mit Intl.DateTimeFormat.

nj.format.date("2026-07-23", "de-DE");
// typischerweise "23.7.2026"

nj.format.date("2026-07-23T18:30:00", "de-DE", {
  dateStyle: "long",
  timeStyle: "short"
});
Ungültige Datumswerte können einen RangeError auslösen. Bei externen Eingaben sollte vorher nj.validate.date() verwendet werden.

nj.format.bytes()

nj.format.bytes(bytes[, decimals = 2]) → string

Formatiert eine Byte-Anzahl in B, KB, MB, GB, TB oder PB. Grundlage ist 1024.

nj.format.bytes(0);          // "0 B"
nj.format.bytes(1024);       // "1 KB"
nj.format.bytes(1536);       // "1.5 KB"
nj.format.bytes(1048576);    // "1 MB"
nj.format.bytes(1234567, 2); // "1.18 MB"

Die Nachkommastellen werden mit toFixed() begrenzt und anschließend über parseFloat() von unnötigen Nullen befreit.

Praxisbeispiele

Preise in einer Tabelle

const rows = products.map(product => ({
  ...product,
  priceFormatted: nj.format.money(product.price)
}));

nj.render("#products", template, { rows });

Dashboard-Kennzahl

const conversionRate = orders / visitors;

nj("#conversion").text(
  nj.format.percent(conversionRate, "de-DE", {
    maximumFractionDigits: 1
  })
);

Dateigröße vor Upload

input.addEventListener("change", () => {
  const file = input.files[0];
  nj("#file-size").text(
    file ? nj.format.bytes(file.size) : ""
  );
});

Datum nur nach Prüfung formatieren

const value = apiResponse.created_at;

const output = nj.validate.date(value)
  ? nj.format.date(value, "de-DE", { dateStyle: "medium" })
  : "Ungültiges Datum";

Grenzen des aktuellen Moduls

  • Keine Parser für lokalisierte Zahlen, Währungen oder Datumswerte.
  • Keine Formatierung von Dauer, Telefonnummern oder relativen Zeitangaben.
  • Keine zentrale globale Locale-Konfiguration innerhalb von nj.format.
  • money() akzeptiert keine zusätzlichen Intl-Optionen.
  • bytes() unterstützt Einheiten nur bis PB.
  • Fehler ungültiger Währungs-, Locale- oder Datumswerte werden nicht intern abgefangen.

Diese Grenzen entsprechen dem tatsächlich vorhandenen Stand in nojquery.core.js.
