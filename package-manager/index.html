Paketmanager

Wähle die Module für dein individuelles ZIP-Paket. Core bleibt immer eingeschaltet. Benötigte Abhängigkeiten werden automatisch hinzugefügt. Der Download wird direkt über PHP erzeugt.

Die ZIP-Datei enthält nojquery.custom.js, die einzelnen Moduldateien, die Konfiguration und die API-Beispiele. Voraussetzung: Apache mit PHP 8.1 oder neuer; keine Python-Installation und keine PHP-ZIP-Erweiterung nötig.
